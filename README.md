# 2048 Game

A modern, responsive implementation of the classic 2048 puzzle game built with clean vanilla JavaScript, HTML5, and SCSS. The objective is to slide numbered tiles on a grid to combine them and reach the elusive 2048 tile.

## 🚀 Live Demo

Play the game online: [Live Demo](https://goshulyakvitalik-sudo.github.io/VitaliH/)

## 🛠 Technologies Used

- **Core**: HTML5, CSS3, Modern JavaScript (ES6+)
- **Styling**: SCSS (BEM methodology, Flexbox, CSS Grid)
- **Tooling**: Gulp, Node.js, npm
- **Code Quality**: ESLint, Stylelint

## ✨ Features

- **Core Gameplay Mechanics**: Full support for shifting, merging matching tiles, generating random tiles (2 or 4), and scoring.
- **Controls**: Smooth navigation using keyboard arrow keys and on-screen gesture/touch controls for mobile screens.
- **Score Tracking**: Real-time score counter with automatic local storage saving for the personal best (Best Score).
- **Game Status Detection**: Automatic recognition of game-winning state (reaching 2048) and game-over state (no valid moves remaining).
- **Restart & State Reset**: Instant game restart button allowing players to reset the board anytime.
- **Responsive Layout**: Pixel-accurate and fluid layout tailored for desktop, tablet, and mobile displays.
